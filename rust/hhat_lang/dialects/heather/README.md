# Heather dialect


## Overview

Heather dialect is the first dialect for H-hat language family. It comes with the H-hat compiler to showcase the ecosystem's capabilities.


In this folder you will find: 
- the compiler implementation at [src/ccompiler/](src/compiler)
- the IR implementation, with:
  - HIR at [src/ir/hir/](src/ir/hir)
  - MIR at [src/ir/hir/](src/ir/mir)
- the Q3L connectors at [src/q3l/](src/q3l)
- the Cranelift implementation at [src/cranelift/](src/cranelift)
- the toolchain connectors and implementation at [src/toolchain/](src/toolchain) 


## Installation

To install Heather, there are a few methods, and they will be available here and at [the documentation](https://docs.hhat-lang.org).
