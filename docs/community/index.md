## Community Channels

### Discord Server

The primary hub for the H-hat community is the **Unitary Foundation Discord server**.

**Join the `#h-hat` channel**: [discord.unitary.foundation](http://discord.unitary.foundation)

What you'll find:

- 💬 **General Discussion**: Talk about H-hat, quantum computing, and related topics
- 🆘 **Help & Support**: Get assistance with installation, code, and troubleshooting
- 📢 **Announcements**: Stay updated on releases and important news
- 🤝 **Collaboration**: Find contributors and discuss feature development
- 🎉 **Community Events**: Participate in coding sessions, talks, and workshops

**Discord Guidelines:**

- Be respectful and welcoming
- Search before asking (someone might have asked already!)
- Share code snippets using code blocks
- Help others when you can
- Have fun and learn together!

### GitHub Discussions

For longer-form discussions and proposals:

**Visit**: [GitHub Discussions](https://github.com/hhat-lang/hhat_lang/discussions)

Topics include:

- 💡 Ideas and feature proposals
- 🔬 Research and algorithm discussions
- 📖 Documentation improvements
- 🎓 Learning resources
- 🏗️ Architecture and design decisions

### GitHub Issues

For bug reports and tracked feature requests:

**Visit**: [GitHub Issues](https://github.com/hhat-lang/hhat_lang/issues)

When opening an issue:

- Search existing issues first
- Use appropriate labels
- Provide clear reproduction steps for bugs
- Include version information
- Be as specific as possible

## Code of Conduct

H-hat is committed to providing a welcoming and inclusive environment for everyone.

### Our Pledge

We pledge to make participation in H-hat a harassment-free experience for everyone, regardless of:

- Age, body size, disability, ethnicity
- Gender identity and expression
- Level of experience
- Nationality, personal appearance
- Race, religion
- Sexual identity and orientation

### Expected Behavior

- Be respectful and considerate
- Welcome newcomers warmly
- Accept constructive criticism gracefully
- Focus on what's best for the community
- Show empathy towards others

### Unacceptable Behavior

- Harassment, trolling, or inflammatory comments
- Personal attacks or insults
- Publishing others' private information
- Any conduct inappropriate in a professional setting

### Reporting

If you experience or witness unacceptable behavior:

1. Contact Discord moderators (use @moderator)
2. Email the Unitary Foundation
3. Report through GitHub if applicable

All reports will be reviewed and investigated promptly and fairly.

[Read full Code of Conduct →](code_of_conduct.md)
