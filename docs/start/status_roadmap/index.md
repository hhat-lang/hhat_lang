

# Status & Roadmap


**Status**: pre-0.3beta


H-hat project is under active development. We are moving toward the release of version `0.3`, the first complete working version of the project. To keep track on its current status, take a look at the [issues](https://github.com/hhat-lang/hhat_lang/issues), [pull requests](https://github.com/hhat-lang/hhat_lang/pulls), [discussions](https://github.com/hhat-lang/hhat_lang/discussions), and [Discord channel](https://discord.gg/J8udsUNRnk). Announcements related to status, roadmap and project development are also published under this documentation [Blog page](../../blog/index.md) section.
