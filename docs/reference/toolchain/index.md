
# Toolchain framework

!!! info

    Work in progress. More information is added as its development progresses.


The toolchain framework is where the CLI `hat`, used for project management, lives as well as the infrastructure responsible for interfacing with the compiler and the user, the dialect native compiler and the proof assistant compiler, and so on. 

It includes:

- creating a new project
- creating files
- updating the project
- building the project executable
- building the documentation
- building the proofs
- running the executable
- debugging compilation passes
