
# H-hat dialects

H-hat language family enables dialects to be built following strict rules to keep compliance with its rule system, and to provide a consistent experience for users programming in H-hat.

H-hat ecosystem ships with [Heather](heather/index.md), a simple but reasonable programming language. It has all the minimum features required by H-hat rule system and compiler framework with a consistent grammar to improve the ease of coding.

You can also [build your own dialect](build_your_own_dialect.md).
