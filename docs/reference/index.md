
# Reference

References for the H-hat ecosystem can be found below.


## Glossary

A glossary is available containing the list of acronyms and terminologies used throughout this documentation. It covers basic terms such as QPU, IR, and compiler pass. You can find it at the [Glossary](glossary.md) page. The page is filled dynamically, so new entries are added from time to time.


## Rule system

The rule system is used to define expected behaviors for the H-hat compliant compilers. You can find more information at the [Rule system](rulesystem/index.md) page.


## Heather dialect

Heather is a programming language shipped with H-hat that aims at providing the minimal useful features a H-hat language should have while being compliant with the rule system. You can find more find more about at [Heather dialect](dialects/heather/index.md) page.


## Dialects

Dialects are programming languages that share the H-hat infrastructure and comply with the rule system. Find more about them at the [Dialects](dialects/index.md) page.


## Compiler framework

The compiler framework provides means for dialect builders and their compilers to express internal H-hat features without having to write them from scratch. It provides standardization on compilation passes, diagnostics and future interoperability between dialects. You can find more at the [Compiler framework](compiler/index.md) page.


## Toolchain framework

H-hat has a toolchain framework that enables dialect builders to import features without the need to write them from scratch. Those tools include the CLI that consists mainly of the project creation and management. More information at [Toolchain framework](toolchain/index.md) page.
