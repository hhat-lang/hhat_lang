# What, Why, How

Answer your questions on [what is H-hat](#what-is-h-hat), [why H-hat](#why-h-hat), and [how to use H-hat](#how-to-use-h-hat).


## What is H-hat

H-hat is a rule system, compiler framework, and a statically typed, functional and distributed-system inspired, <u>hybrid quantum-classical programming language family</u>.
As an ecosystem, H-hat provides all the infrastructure for dialect builders so dialects comply with the high-level abstraction paradigm and rule system. Users benefit from using a higher-level abstraction language with well-formedness principles and a unified toolchain.

_Writing programs with quantum code is as natural as classical code_.

Quantum and classical code may coexist in the same program. Quantum paradigm contains quantum types, quantum literals, quantum variables and quantum functions.


## Why H-hat

H-hat is intended to be used for designing problem-domain programs. Therefore:

- H-hat abstracts away the physics from the user
- Focus on the problem domain instead of physical constraints

A new layer of abstraction unveils new possibilities to think and write about problems. That is the core of H-hat ecosystem. Just like Fortran revolutionalized as the first compiled programming language, H-hat hopes that having the capability to think of the problem and not the physics will enable a new wave of development and creativity.


## How to use H-hat

To use H-hat is necessary to use a programming language that implements H-hat. Luckily H-hat ships with Heather, a reference dialect. You can find it at the [Heather dialect](../reference/dialects/heather/index.md) page.
