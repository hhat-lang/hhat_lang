# H-hat Toolchain

The CLI for managing projects in H-hat is developed in Python. It is not fully featured, containing only creation of new project and files (behavioral, types, constants), and update of project (to match `docs/` with `src/`).

Check [H-hat issues](https://github.com/hhat-lang/hhat_lang/issues) for existing issues or create a new issue to propose new features, file bug reports or improvements.
