
# Heather

Heather is the reference programming language shipped with H-hat. It is named after a [plant](https://en.wikipedia.org/wiki/Calluna)[^1] and a [song](https://en.wikipedia.org/wiki/Crosswinds_(Billy_Cobham_album)#Side_two)[^2].


[^1]: Scientific name: _Calluna vulgaris_, a small flowering shrub.
[^2]: Billy Cobham's Crosswinds album, second track of side two.


The language is being developed to present all the concepts H-hat aims to accomplish: high-level abstraction language, rule system for strong compliance on quantum rules and quantum physics-respecting constraints, and to present a quantum software engineering side closer to the classical one.

It has some basic features, as well simple syntax; grammar strict structure and almost no ambiguity (if any) highlights Heather capabilities, promoting code that is easy to write, read, and reason about.

You can find the following under the sub-pages:

- [Syntax](syntax.md) page
- [Grammar](grammar.md) page


## Language features

- Statically typed
- Ownership, borrowing and drop
- No garbage collector
- JIT compiler by [Cranelift](https://cranelift.dev/)
- Call-oriented functions and operators
