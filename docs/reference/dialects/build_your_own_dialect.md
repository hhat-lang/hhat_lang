
# Build your own H-hat dialect

!!! info

    This section is a work in progress.


Dialects are programming languages that follow some common rules or behaviors, usually according to the main programming language's directive.

H-hat is not a programming language _per se_; it instead defines, designs and creates the structure, logic and frameworks in which programming languages can utilize to be compliant with H-hat principles.


More information on how to get started with dialect creation will follow in this page.
